# Security Policy

Please report suspected vulnerabilities privately through GitHub Security
Advisories for `perspectivefi/spectra-oracles-stellar-public`. Do not open a
public issue for an undisclosed vulnerability.

Only the latest release on the default branch is supported. Reports should
include affected code, impact, reproduction steps, and any proposed mitigation.

The contracts are provided under the terms and warranty disclaimer in
`LICENSE`. An audit reduces risk but does not guarantee the absence of defects.
